# Eve V Fix-It

A portable Windows app that detects, applies (with confirmation) and **verifies**
every software-fixable issue from this knowledge base, and lists the hardware /
firmware / manual ones with links.

> ⚠️ Read [`docs/00-read-first.md`](../../docs/00-read-first.md) first. This is a
> community tool built from **one unit** + public sources. Findings can be wrong or
> not apply to your batch. It touches power settings, devices and Windows servicing
> — nothing here is an official manual. Your risk.

## Get it

| | |
|---|---|
| **One file** | Download `EveV-FixIt.exe` from the [latest Release](https://github.com/Ollleey/eve-v-2017-kb/releases). Double-click. Accept the UAC prompt. |
| **No .exe** (AV flags it / you don't trust binaries) | Download this folder, run **`Start-EveV-FixIt.bat`** — same app, straight from the PowerShell script. |

### The Defender / SmartScreen warning

`EveV-FixIt.exe` is **not code-signed** (no cert), and it's a PowerShell script
wrapped by [ps2exe](https://github.com/MScholtes/PS2EXE). Windows Defender,
Malwarebytes or SmartScreen may flag it or show "Windows protected your PC".

- **SmartScreen:** click *More info → Run anyway*.
- **Defender quarantine:** either add an exclusion, or just use
  `Start-EveV-FixIt.bat` (the raw script), or build it yourself: `powershell -File
  build.ps1`.
- Every Release lists the **SHA-256** so you can verify the download.

## What it does

- Runs a read-only scan of ~25 checks on launch, grouped by area.
- Each card shows a status pill, what was found, an **Open knowledge base** link,
  and — where a safe automated fix exists — a button.
- After any fix it **re-runs that check** and shows `Fixed`, `Applied — reboot to
  finish`, or the new state.
- **Fix all safe items** applies only the quick, reversible fixes in one go.
- **Export report** writes a Markdown summary (same shape as `eve-v-healthcheck.ps1`).

### Fix tiers

| Tier | Behaviour | Examples |
|---|---|---|
| **Safe** (green, in "Fix all") | quick, reversible | disable Fast Startup · Wi-Fi power-saving off · disable wake for touch panel + keyboard · lid-close = "Do nothing" · enable Hibernate · SSD ReTrim · `chkdsk /scan` (read-only) · power reports |
| **Behaviour** (amber, one at a time) | reversible, changes how the device acts or a security setting — always asks first, shows how to undo | disable the (dead) fingerprint device · re-bind a failed Wacom pen driver · turn **off** Memory Integrity so you can undervolt |
| **Corrective** (amber, one at a time) | non-destructive Windows repair, not literally "undoable" but standard | `DISM /RestoreHealth` + `sfc /scannow` · Windows Update cache reset |
| **Destructive** (red, gated) | cannot be undone, needs a reboot — a "I have a backup" box must be ticked, never batched | `chkdsk C: /f` (offline filesystem repair) |
| **Manual / Hardware / Info** (grey, no button) | can't be fixed by software | audio smart-amp driver · Wi-Fi driver version · thermal / PWM / battery calibration · firmware (with a brick warning) · keyboard flex · RTC cell · EFI-shell recovery · Alpine Ridge RTD3 ("not a fault") |

Long operations (DISM, sfc, chkdsk, ReTrim) run in their **own console window** so
the app stays responsive — click **Re-check** on the card when they finish.

## Requirements

- Windows 10 / 11, any edition. Needs .NET Framework 4.x (always present).
- Administrator rights to apply fixes (the app requests elevation; the scan works
  without it, minus one check).
